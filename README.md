# Movie Recommendation System

A content-based movie recommendation system using TF-IDF and TMDB API integration.

## Features

- **TF-IDF Based Recommendations**: Uses cosine similarity on TF-IDF vectors to suggest similar movies based on content features
- **TMDB Integration**: Fetches real-time movie data, posters, and details from The Movie Database API
- **FastAPI Backend**: High-performance REST API for movie recommendations and search
- **Streamlit Frontend**: Interactive web interface for browsing and discovering movies

## Tech Stack

- **Backend**: FastAPI, Python, scikit-learn, pandas, numpy
- **Frontend**: Streamlit
- **API**: TMDB (The Movie Database)
- **ML Model**: TF-IDF Vectorizer for content-based filtering
